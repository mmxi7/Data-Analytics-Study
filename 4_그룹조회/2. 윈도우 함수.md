# 윈도우 함수

**행과 행 간의 관계를 쉽게 정의**하는 함수

<br>

## RANK

특정 열의 값을 기준으로 **순위**를 계산하는 함수

예) 2등이 2명이라면 순위는 `1 2 2 4 5`

### 기본 구문

```sql
SELECT ...
      RANK() OVER (...) AS
FROM;
```

예시)

학생들의 키가 큰 순서대로 순위를 구한다.

```sql
SELECT name, height,
        RANK() OVER (ORDER BY height DESC) AS '키순위'
FROM students
LIMIT 0, 5;
```

<br>

## DENSE_RANK

순위를 계산하지만 동점자가 있어도 다음 순위를 건너뛰지 않음

예) 2등이 2명이라면 순위는 `1 2 2 3 4`


### 기본 구문

```sql
SELECT ...
       DENSE_RANK() OVER (...) AS 순위
FROM;
```

예)

```sql
SELECT name, height,
       DENSE_RANK() OVER (ORDER BY height DESC) AS '키순위'
FROM students
LIMIT 0, 5;
```

<br>

## PARTITION BY

데이터를 지정한 기준에 따라 나눈 뒤 **각 그룹 안에서 윈도우 함수를 계산**할 때 사용

### 기본 구문
```sql
SELECT ...
       RANK() OVER (PARTITION BY ... ORDER BY ...) AS ...
FROM;
```

예)

3학년 학생을 대상으로 **각 학과 안에서** 키가 큰 순서대로 순위를 구한다.

```sql
SELECT name, department_id, height,
       RANK() OVER (
           PARTITION BY department_id
           ORDER BY height DESC) AS '학과별 키 순위'
FROM students
WHERE grade = 3;
```
