# 숫자 함수
숫자 데이터를 **계산하거나 원하는 형태로 변환**

<br>

### `ABS()`
숫자의 **절댓값**을 반환

### `POWER()`
숫자의 **제곱값**을 계산

### `ROUND()`
숫자를 지정한 소수점 자리까지 **반올림**

### `CEIL()`
숫자의 소수점 이하를 **올림**하여 정수로 반환

### `FLOOR()`
숫자의 소수점 이하를 **내림**하여 정수로 반환

### `TRUNCATE()`
숫자를 지정한 소수점 자리에서 **잘라냄**

| 함수 | 처리 방식 | 예시 |
|---|---|---|
| `ROUND(3.8)` | 반올림 | `4` |
| `CEIL(3.2)` | 올림 | `4` |
| `FLOOR(3.8)` | 내림 | `3` |
| `TRUNCATE(3.1415, 2)` | 지정한 자리에서 자름 | `3.14` |

### `MOD()`
숫자를 나눈 후 **나머지**를 반환

### `SIGN()`
숫자가 양수인지, 0인지, 음수인지에 따라 값을 반환

<br>

## 정리

| 함수 | 기능 |
|---|---|
| `ABS()` | 절댓값 반환 |
| `POWER()` | 거듭제곱 계산 |
| `ROUND()` | 지정한 소수점 자리까지 반올림 |
| `CEIL()` | 소수점 이하 올림 |
| `FLOOR()` | 소수점 이하 내림 |
| `TRUNCATE()` | 지정한 소수점 자리에서 자름 |
| `MOD()` | 나눗셈의 나머지 반환 |
| `SIGN()` | 양수, 0, 음수 판별 |
