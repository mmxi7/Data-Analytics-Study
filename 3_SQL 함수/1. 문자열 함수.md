# SQL 함수

**함수의 종류**
- **단일 행 함수**: 각 행마다 함수를 적용하여 하나의 결과를 반환
- **집계 함수** : 여러 행을 하나의 결과로 요약

<br>

### `UPPER()`
문자열을 **대문자**로 변환

### `LOWER()`
문자열을 **소문자**로 변환

### `CHAR_LENGTH()`
문자열의 **문자 수(글자 수)**를 반환

### `CONCAT()`
여러 문자열을 **하나의 문자열로 연결**

### `SUBSTRING()`
문자열의 특정 위치부터 원하는 길이만큼 **문자를 추출**

### `LEFT() / RIGHT()`
문자열의 왼쪽 또는 오른쪽에서 원하는 글자 수만큼 추출

### `TRIM()`
문자열의 **앞뒤 공백을 제거**한다.
- 중간에 있는 공백은 제거하지 않음

### `REPLACE()`
문자열에서 특정 문자열을 찾아 **다른 문자열로 변경**

### `INSTR()`
문자열 안에서 특정 문자열이 등장하는 **위치**를 반환

### `LPAD() / RPAD()`
문자열을 지정한 길이까지 특정 문자로 채운다.

### `FORMAT()`
숫자를 **천 단위 쉼표와 지정한 소수점 자리수** 형태로 출력

<br>

## 정리

| 함수 | 기능 |
|---|---|
| `UPPER()` | 문자열을 대문자로 변환 |
| `LOWER()` | 문자열을 소문자로 변환 |
| `CHAR_LENGTH()` | 문자열의 글자 수 반환 |
| `CONCAT()` | 문자열 연결 |
| `SUBSTRING()` | 특정 위치부터 문자열 추출 |
| `LEFT()` | 왼쪽부터 문자열 추출 |
| `RIGHT()` | 오른쪽부터 문자열 추출 |
| `TRIM()` | 문자열 앞뒤 공백 제거 |
| `REPLACE()` | 특정 문자열을 다른 문자열로 변경 |
| `INSTR()` | 특정 문자열의 위치 반환 |
| `LPAD()` | 왼쪽을 특정 문자로 채움 |
| `RPAD()` | 오른쪽을 특정 문자로 채움 |
| `FORMAT()` | 숫자에 천 단위 쉼표 및 소수점 적용 |

### 01

학과명(`dname`)을 모두 소문자로 변환하고, 학과명이 5글자를 초과하는 경우만 조회하시오.

```sql
SELECT LOWER(dname) AS lower_dname
FROM departments
WHERE CHAR_LENGTH(dname) > 5;
```

### 02

과목명(`name`)의 앞 2글자와 학점을 결합해 `"과목코드: AA-3"` 형식으로 출력하시오.  
**(예: `데이터베이스` 3학점 → `과목코드: 데이-3`)**

```sql
SELECT CONCAT('과목코드: ', LEFT(name, 2), '-', credit) AS subject_code
FROM subjects;
```

### 03

학생의 전화번호(`phone`) 중, 가운데 4자리를 추출하여 출력하시오.  
전화번호는 `"xxx-1234-5678"` 혹은 `"xx-1234-5678"` 형식으로 저장되어 있습니다.

```sql
SELECT name, SUBSTR(phone, INSTR(phone, '-') + 1, 4) AS mid_number
FROM students;
```

### 04

전화번호가 저장되어 있는 학과 중에서 학과명을 오른쪽으로 공백을 추가하여 15자 고정 폭으로 출력하고,  
전화번호는 왼쪽으로 공백을 추가하여 15자 고정 폭으로 출력하시오.  
두 값을 합쳐 하나의 문자열로 출력하시오.

```sql
SELECT CONCAT(
          RPAD(dname, 15),
          LPAD(phone, 15))
FROM departments
WHERE phone IS NOT NULL;
```

### 05

학생의 이름(`name`)과 이메일의 아이디 부분(이메일에서 `@` 앞부분)을 추출하여 출력하시오.

```sql
SELECT name, SUBSTR(email, 1, INSTR(email, '@') - 1) AS email_id
FROM students;
```
