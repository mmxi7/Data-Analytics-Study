# SQL 함수

**함수의 종류**
- **단일 행 함수**: 각 행마다 함수를 적용하여 하나의 결과를 반환
- **집계 함수** : 여러 행을 하나의 결과로 요약

<br>

### `UPPER()`
문자열을 **대문자**로 변환

### `LOWER()`
문자열을 **소문자**로 변환

### `CHAR_LENGTH()`
문자열의 **문자 수(글자 수)**를 반환

### `CONCAT()`
여러 문자열을 **하나의 문자열로 연결**

### `SUBSTRING()`
문자열의 특정 위치부터 원하는 길이만큼 **문자를 추출**

### `LEFT() / RIGHT()`
문자열의 왼쪽 또는 오른쪽에서 원하는 글자 수만큼 추출

### `TRIM()`
문자열의 **앞뒤 공백을 제거**한다.
- 중간에 있는 공백은 제거하지 않음

### `REPLACE()`
문자열에서 특정 문자열을 찾아 **다른 문자열로 변경**

### `INSTR()`
문자열 안에서 특정 문자열이 등장하는 **위치**를 반환

### `LPAD() / RPAD()`
문자열을 지정한 길이까지 특정 문자로 채운다.

### `FORMAT()`
숫자를 **천 단위 쉼표와 지정한 소수점 자리수** 형태로 출력

<br>

## 정리

| 함수 | 기능 |
|---|---|
| `UPPER()` | 문자열을 대문자로 변환 |
| `LOWER()` | 문자열을 소문자로 변환 |
| `CHAR_LENGTH()` | 문자열의 글자 수 반환 |
| `CONCAT()` | 문자열 연결 |
| `SUBSTRING()` | 특정 위치부터 문자열 추출 |
| `LEFT()` | 왼쪽부터 문자열 추출 |
| `RIGHT()` | 오른쪽부터 문자열 추출 |
| `TRIM()` | 문자열 앞뒤 공백 제거 |
| `REPLACE()` | 특정 문자열을 다른 문자열로 변경 |
| `INSTR()` | 특정 문자열의 위치 반환 |
| `LPAD()` | 왼쪽을 특정 문자로 채움 |
| `RPAD()` | 오른쪽을 특정 문자로 채움 |
| `FORMAT()` | 숫자에 천 단위 쉼표 및 소수점 적용 |
