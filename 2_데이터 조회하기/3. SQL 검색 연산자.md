# SQL 검색 연산자

| 연산자 | 의미 |
|---|---|
| `BETWEEN A AND B` | A 이상 B 이하 |
| `NOT BETWEEN A AND B` | A 이상 B 이하의 범위가 아닌 값 |
| `IN (값1, 값2, ...)` | 목록 중 하나와 일치 |
| `NOT IN (값1, 값2, ...)` | 목록에 포함되지 않음 |
| `LIKE` | 특정 문자열 패턴과 일치 |
| `NOT LIKE` | 특정 문자열 패턴과 일치하지 않음 |
| `IS NULL` | NULL인 데이터 |
| `IS NOT NULL` | NULL이 아닌 데이터 |
