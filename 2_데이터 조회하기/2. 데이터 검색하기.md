## WHERE 절

```sql
SELECT 컬럼명
FROM 테이블명
WHERE 검색조건
ORDER BY 정렬기준
LIMIT 시작위치, 개수;
```

### 비교 연산자

| 연산자 | 의미 |
|---|---|
| `=` | 같다 |
| `!=` | 다르다 |
| `<>` | 다르다 |
| `<` | 작다, 미만 |
| `<=` | 작거나 같다, 이하 |
| `>` | 크다, 초과 |
| `>=` | 크거나 같다, 이상 |

### 논리 연산자

여러 개의 검색 조건을 함께 사용할 때 논리 연산자를 사용한다.

| 연산자 | 의미 |
|---|---|
| `AND` | 여러 조건을 모두 만족 |
| `OR` | 하나 이상의 조건을 만족 |
| `NOT` | 조건을 부정 |
