# OUTER JOIN

### OUTER JOIN이란?
두 테이블을 JOIN할 때, **기준 테이블의 모든 행을 결과에 포함**

### 종류
- LEFT OUTER JOIN
- RIGHT OUTER JOIN
- FULL OUTER JOIN (성능에 불리, 거의 사용하지 않음)

### 구문
```sql
SELECT ...
FROM ...
LEFT/RIGHT JOIN ... ON ...
```

# UNION
